# 입력 데이터 위치

[MovieLens 공식 배포 파일](https://files.grouplens.org/datasets/movielens/ml-latest-small.zip)을 내려받아 압축을 푼 뒤, 다음 두 파일을 이 폴더에 넣으세요.

- `movies.csv`
- `ratings.csv`

노트북에서 사용하는 상대 경로는 `data/movies.csv`, `data/ratings.csv`입니다.

데이터 CSV는 Git 업로드 대상에서 제외되어 있습니다. 출처와 이용 조건은 [공식 README](https://files.grouplens.org/datasets/movielens/ml-latest-small-README.html)를 확인하세요.
