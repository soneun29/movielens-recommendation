# 영화 추천 만들어보기

MovieLens 데이터를 가지고 간단한 영화 추천을 해본 프로젝트입니다.
추천 시스템을 공부해보고 싶어서 시작했고, 우선 pandas로 데이터를 정리하고 사용자가 좋아하는 장르를 이용하는 방식부터 해봤습니다.

아직 복잡한 추천 모델을 만든 것은 아니고, 평균 평점으로 추천했을 때와 평가 수도 같이 고려했을 때 결과가 어떻게 다른지 확인하는 데 집중했습니다.

## 해본 것

1. 영화 데이터와 평점 데이터를 불러와서 크기와 컬럼 확인하기
2. movieId로 두 데이터를 합치고 결측치 확인하기
3. 영화마다 평균 평점과 평가 수 구하기
4. 사용자가 4점 이상 준 영화에서 많이 나온 장르 5개 찾기
5. 그 장르가 들어 있는 영화 중 이미 평가한 영화는 빼기
6. 평균 평점과 가중 평점으로 각각 10개씩 추천해서 비교하기
7. 사용자 번호를 바꿔서 쓸 수 있게 함수로 만들기

처음에는 사용자 1번을 기준으로 진행했고, 뒤에서는 함수에 사용자 2번도 넣어서 결과를 비교했습니다.

## 결과를 보면서 생각한 점

평균 평점만 높은 순서로 뽑으면 평가가 한두 개뿐인 영화도 5점이라서 위에 나왔습니다. 그래서 평균만 보는 것보다 몇 명이 평가했는지도 같이 봐야겠다고 생각했습니다.

가중 평점은 아래 식을 사용했습니다.

```text
WR = (v / (v + m)) * R + (m / (v + m)) * C

v = 영화의 평가 수
R = 영화의 평균 평점
C = 전체 평점 평균
m = 100으로 설정
```

평가 수가 적으면 전체 평균의 영향을 더 많이 받는 방식으로 이해했습니다. 여기서 100은 평가 수가 100개 미만인 영화를 제외하는 기준은 아닙니다. 이번에는 100으로 해봤고, 이 값이 가장 좋은지는 아직 비교하지 못했습니다.

노트북에 저장된 결과에서는 평균 평점 TOP 10과 가중 평점 TOP 10에 겹치는 영화가 없었습니다. 같은 후보에서 뽑았는데 기준에 따라 결과가 꽤 달라지는 것을 볼 수 있었습니다.

사용자 1번과 2번의 추천 결과에는 겹치는 영화가 1개 있었습니다. 그리고 사용자 1번이 이미 평가한 영화가 다시 추천되는지도 확인했는데 0개로 나왔습니다. 다만 이 결과만으로 추천이 잘된다고 말할 수는 없을 것 같습니다.

## 아직 부족한 점

- 좋아하는 장르가 하나라도 포함되면 후보에 넣어서 조건이 넓은 편입니다.
- 장르로 후보를 고른 다음에는 같은 가중 평점 기준으로 정렬해서 개인 취향을 자세히 반영하지는 못합니다.
- 순위 비교 표에서 일부 영화 제목과 평점이 NaN으로 나오는 부분이 남아 있습니다. 두 목록을 합칠 때 필요한 정보가 한쪽에만 있어서 생긴 부분입니다.
- 추천 정확도를 평가하지는 못했습니다. 나중에는 데이터를 나눠서 실제로 좋아한 영화를 얼마나 추천하는지 확인해보고 싶습니다.

## 실행하기

사용한 데이터는 MovieLens의 **ml-latest-small**입니다. 저장된 출력 기준으로 영화 9,742개, 평점 100,836개입니다.

1. [MovieLens 데이터 다운로드](https://files.grouplens.org/datasets/movielens/ml-latest-small.zip)
2. 압축을 풀고 `movies.csv`, `ratings.csv` 두 개를 `data` 폴더에 넣기
3. 필요한 패키지를 설치하고 노트북 열기

```bash
python -m pip install pandas matplotlib notebook
python -m notebook
```

폴더는 이렇게 맞추면 됩니다.

```text
movielens-recommendation/
├─ 03_movielens_eda.ipynb
├─ README.md
└─ data/
   ├─ README.md
   ├─ movies.csv
   └─ ratings.csv
```

CSV 원본은 저장소에 넣지 않았습니다. `tags.csv`와 `links.csv`는 이번 코드에서 사용하지 않습니다.

`03_movielens_eda.ipynb`를 열어서 커널을 재시작하고 위에서부터 전체 실행하면 됩니다. 함수 정의 셀에 실행 번호가 비어 있어서 중간부터 실행하기보다는 처음부터 실행하는 것이 좋습니다.

마지막 셀에서는 추천 결과를 `recommendations_user1.csv`로 저장합니다. 이 파일은 실행하면 만들어지므로 미리 준비하지 않아도 됩니다.
